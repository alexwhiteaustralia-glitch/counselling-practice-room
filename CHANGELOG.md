# Changelog

## 16.0.0

First release as a Claude plugin. Content matches version 16 of the Practice Room, split into a core skill and reference files so Claude loads only what each mode needs.

- Replay: give Claude the transcript of a real training session, get a short review, then re-run it from the moment that mattered with a stand-in client, and rewind to try again.
- Added a "training only" note to the first welcome and a clear line on what to do if a student's own distress comes up.
- Progress reports and "pick up from last time" now read only the student's own log files, or ask the student to paste a note.

## Earlier versions (shared as a single file)

- 15: stored setup card, observer reminders kept to the moments that matter, 30 to 50 minute lengths.
- 14: edge drill, built from the student's running edges in the practice log.
- 13: expanded motivational interviewing practice (rulers, amplified reflection, Ask-Offer-Ask).
- 12: setup card, voice handover, spoken arrival and a fuller self-reflection step in the debrief.
